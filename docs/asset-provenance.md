# Cat asset

Input: the orange cat image attached by the user on 2026-10-18.

Output: `assets/cikung.png`, a transparent sprite prepared with the built-in image generation tool. This is a generated cutout rendition of the supplied cat, not a pixel-identical background removal. CouCou artwork was not used.

Prompt used:

> Use case: background-extraction. Edit target: attached orange cat illustration. Asset type: transparent PNG sprite for a desktop companion named Cikung. Remove only the white background and empty outer margins, leaving the entire cat including all whiskers, ears, feet and tail. Preserve the cat's orange colors, subtle texture, seated pose, friendly face, proportions and all details as closely as possible. Center the full cat with a small transparent safety margin. Actual alpha transparency, no ground shadow, no text, no additional objects.

## Original completion sound for 0.10

`assets/agent-complete.wav` is an original synthesized two-note chime: 880 Hz and 1174.66 Hz with soft attack/decay, 44.1 kHz mono 16-bit PCM, 460 ms. It was generated locally from sine waves with Python's standard-library `wave`, `math` and `struct` modules; no recording, downloaded sound, or CouCou audio was used. It is embedded in the executable and released under this project's MIT license. Tests validate its RIFF/PCM layout, duration bounds, amplitude and quiet endpoints.
